## Variável: uma caixinha com etiqueta

Uma variável é um espaço na memória do computador onde você guarda um valor. Ela tem três coisas:

- um **tipo**: o que cabe nela (número inteiro, número com vírgula, letra...);
- um **nome**: a etiqueta, para você achar a caixinha depois;
- um **valor**: o que está guardado lá dentro agora.

```c
int idade = 20;
float altura = 1.75;
char inicial = 'C';
```

Na memória, dá para imaginar assim (os endereços são só um exemplo):

O valor pode mudar quando você quiser (por isso o nome *variável*):

```c
int pontos = 0;   // declara e já coloca 0
pontos = 10;      // troca o valor por 10
pontos = pontos + 5; // pega o valor atual (10), soma 5 e guarda: agora é 15
```

<Nota tipo="cuidado" titulo="= não é igualdade">
Em C, `=` significa **guardar** (atribuir). `pontos = pontos + 5` não é uma equação impossível: é "pontos recebe pontos mais 5". Para **comparar** se dois valores são iguais, usamos `==` (vamos ver na aula 4).
</Nota>

## Os tipos básicos

| Tipo | Guarda | Exemplo |
| --- | --- | --- |
| `int` | número inteiro | `int ano = 2026;` |
| `float` | número com vírgula | `float preco = 9.90;` |
| `double` | número com vírgula, com mais precisão | `double pi = 3.14159265;` |
| `char` | **um** caractere, entre aspas simples | `char letra = 'A';` |

Repare: no código, a vírgula decimal é um **ponto**: `9.90`, nunca `9,90`.

## printf: mostrando valores

Para mostrar o valor de uma variável, o `printf` usa **marcadores** dentro do texto. Cada marcador é trocado por um valor, na ordem:

```c
#include <stdio.h>

int main() {
    int idade = 20;
    float altura = 1.75;
    char inicial = 'C';

    printf("Idade: %d anos\n", idade);
    printf("Altura: %.2f m\n", altura);
    printf("Inicial: %c\n", inicial);
    printf("%c tem %d anos e %.2f m\n", inicial, idade, altura);
    return 0;
}
```

```saida
Idade: 20 anos
Altura: 1.75 m
Inicial: C
C tem 20 anos e 1.75 m
```

| Marcador | Usa com | Observação |
| --- | --- | --- |
| `%d` | `int` | d de *decimal* |
| `%f` | `float` e `double` | mostra 6 casas: `1.750000` |
| `%.2f` | `float` e `double` | só 2 casas: `1.75` |
| `%c` | `char` | um caractere |
| `%s` | texto (string) | veremos na aula 5 |

## O que significa o número em `%.1f`?

Você já viu `%f` e `%.2f` na tabela. Não são dois comandos diferentes: **a parte depois do ponto define quantas casas decimais o `printf` deve mostrar**.

```c
#include <stdio.h>

int main() {
    double pi = 3.14159;

    printf("Sem limitar: %f\n", pi);
    printf("Uma casa: %.1f\n", pi);
    printf("Duas casas: %.2f\n", pi);
    printf("Tres casas: %.3f\n", pi);
    return 0;
}
```

```saida
Sem limitar: 3.141590
Uma casa: 3.1
Duas casas: 3.14
Tres casas: 3.142
```

O `%.1f` não muda o valor guardado na variável. Só **formata como o número aparece na tela**, arredondando quando necessário. Você escolhe quantas casas quer mostrar.

## Existem outros marcadores além de `%d` e `%f`?

Sim! Estes são os mais comuns de encontrar em outros códigos. **Não precisa decorar todos agora**: volte a esta tabela quando precisar.

| Marcador no `printf` | Valor esperado | Exemplo de uso |
| --- | --- | --- |
| `%d` ou `%i` | `int` | `printf("%d", idade);` |
| `%f`, `%.1f`, `%.2f` | `float` ou `double` | `printf("%.2f", preco);` |
| `%c` | caractere (`char`) | `printf("%c", letra);` |
| `%s` | texto (sequência de caracteres) | `printf("%s", nome);` |
| `%u` | `unsigned int` (inteiro sem sinal) | `printf("%u", quantidade);` |
| `%ld` | `long` | `printf("%ld", distancia);` |
| `%lld` | `long long` | `printf("%lld", numeroGrande);` |
| `%x` | inteiro sem sinal em hexadecimal | `printf("%x", cor);` |
| `%o` | inteiro sem sinal em octal | `printf("%o", numero);` |
| `%e` | número decimal em notação científica | `printf("%e", pi);` |
| `%p` | endereço de memória (ponteiro) | `printf("%p", (void *)&idade);` |
| `%zu` | `size_t`, usado com `sizeof` | `printf("%zu", sizeof(int));` |
| `%%` | o símbolo `%` literal | `printf("50%%");` |

Mais adiante você vai entender `long`, `unsigned` e ponteiros com calma. Por enquanto, concentre-se em `%d`, `%f`, `%c` e `%s`. A ideia é saber que cada marcador pede um tipo de valor.

<Nota tipo="cuidado" titulo="Posso usar printf(idade) sem um marcador?">
Não. O primeiro argumento do `printf` precisa ser um **texto de formato**. Para mostrar um inteiro, use `printf("%d", idade);`. Para mostrar apenas uma mensagem, `printf("Olá");` funciona sem nenhum marcador, porque o texto já é o que queremos imprimir.
</Nota>

## E o `\n`? Ele também é um marcador?

Não. Os marcadores (`%d`, `%f`...) representam **valores que serão inseridos no texto**. Já o `\n` é uma **sequência de escape**: um comando especial dentro do próprio texto.

| Sequência | O que faz |
| --- | --- |
| `\n` | pula para a próxima linha |
| `\t` | insere uma tabulação |
| `\"` | coloca aspas duplas no texto |
| `\\` | mostra uma barra invertida (`\`) |

```c
#include <stdio.h>

int main() {
    printf("Nome\tIdade\n");
    printf("Ana\t20\n");
    printf("Ela disse: \"Vou aprender C!\"\n");
    printf("Pasta: C:\\projetos\n");
    return 0;
}
```

```saida
Nome    Idade
Ana     20
Ela disse: "Vou aprender C!"
Pasta: C:\projetos
```

O espaço da tabulação pode variar conforme o terminal. E lembra da aula passada? Sem o `\n`, o próximo `printf` começa a escrever onde o anterior parou.

<Nota tipo="dica" titulo="Um detalhe importante para as próximas aulas">
Esta tabela é de formatos do **`printf`**. O `scanf` também usa marcadores, mas algumas regras mudam: para ler um `double`, por exemplo, você usará `%lf` no `scanf`. Vamos continuar agora com a leitura de valores.
</Nota>

## scanf: lendo do teclado

O `scanf` é o contrário do `printf`: ele **lê** o que a pessoa digitou e guarda numa variável.

```c
#include <stdio.h>

int main() {
    int a, b;

    printf("Digite dois números: ");
    scanf("%d %d", &a, &b);

    printf("A soma é %d\n", a + b);
    return 0;
}
```

Teste no OnlineGDB: depois de clicar em **Run**, clique na área de baixo (o console), digite `3 4` e aperte Enter.

```saida
Digite dois números: 3 4
A soma é 7
```

<Nota tipo="cuidado" titulo="O & do scanf">
Repare no `&` antes de `a` e `b`. Ele significa "**o endereço de**". O `scanf` precisa saber **onde** fica a caixinha para colocar o valor lá dentro. Esquecer o `&` é um erro clássico: o programa compila, mas trava ou guarda lixo. Na aula de ponteiros você vai entender isso a fundo.
</Nota>

<Nota tipo="dica" titulo="Nos desafios do GitHub">
Os desafios têm correção automática: o robô compara a sua saída com a esperada, letra por letra. Por isso, nos desafios, **não** escreva "Digite um número:". Mostre só a resposta, exatamente no formato pedido.
</Nota>

## Contas com variáveis

```c
#include <stdio.h>

int main() {
    float nota1, nota2;

    scanf("%f %f", &nota1, &nota2);
    float media = (nota1 + nota2) / 2;

    printf("Média: %.1f\n", media);
    return 0;
}
```

Os parênteses importam: sem eles, `nota1 + nota2 / 2` dividiria só a `nota2`, igual na matemática.

## Resumindo

- Variável = tipo + nome + valor. `=` guarda um valor.
- `printf` mostra valores usando marcadores: `%d`, `%f`, `%.2f`, `%c`.
- `scanf` lê do teclado e precisa do `&` antes da variável.
- No código, número com vírgula usa **ponto**: `1.75`.
