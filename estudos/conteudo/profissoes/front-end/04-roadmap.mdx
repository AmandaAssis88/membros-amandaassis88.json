<Nota tipo="dica" titulo="Projetos para o portfólio">
1. Uma página pessoal (HTML e CSS puros).
2. Uma calculadora ou lista de tarefas (JavaScript).
3. Um app que consome uma API pública, por exemplo a do GitHub, mostrando os repositórios de um usuário (fetch).
4. Uma contribuição real: o onboarding e o estudos da Unidunedev aceitam PRs! Corrigir uma aula ou melhorar um componente conta muito.
</Nota>

## O que costuma aparecer em vagas

- HTML, CSS e JavaScript sólidos.
- React (ou Angular) com TypeScript.
- Consumo de APIs REST.
- Git e trabalho com PRs.
- Responsividade e noções de acessibilidade.

<Nota tipo="ia" titulo="Front-end e IA">
A IA gera componentes muito rápido, mas quem sabe CSS de verdade é quem conserta quando "fica quase certo". Peça para a IA explicar o código que ela gerou, e mexa você mesmo até entender cada linha.
</Nota>

## Resumindo

- HTML e CSS → JavaScript → um framework com TypeScript.
- Publique projetos desde cedo: front-end é para ser visto.
- Contribuir com os sites da Unidunedev já é experiência real.
