<Nota tipo="dica" titulo="Projetos para o portfólio">
1. Uma API de lista de tarefas com banco de dados (o "Olá, mundo" do back-end).
2. A mesma API com login e cada usuário vendo só as suas tarefas.
3. Uma API publicada na internet, com documentação no Swagger.
4. Um README caprichado explicando as rotas, com exemplos de requisição e resposta.
</Nota>

## O que costuma aparecer em vagas

- Uma linguagem e seu framework (Java + Spring, Python + Django/FastAPI, Node + Nest, C# + .NET).
- SQL e um banco relacional (PostgreSQL ou MySQL).
- APIs REST, autenticação e testes.
- Git, Docker e noções de nuvem.

<Nota tipo="ia" titulo="Back-end e IA">
A IA escreve um CRUD em segundos. O que ela não decide por você: as regras de negócio certas, a segurança e o que acontece quando mil pessoas fazem a mesma coisa ao mesmo tempo. Revise com atenção dobrada tudo que envolve senha, permissão e dinheiro.
</Nota>

## Resumindo

- Base → uma linguagem a fundo → banco e SQL → primeira API → API de verdade.
- Segurança e testes não são extras: fazem parte.
- A API do chat é o projeto perfeito para treinar tudo isso.
