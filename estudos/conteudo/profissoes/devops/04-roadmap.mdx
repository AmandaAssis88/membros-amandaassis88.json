<Nota tipo="dica" titulo="Projetos para o portfólio">
1. Um script em Bash ou Python que automatiza algo chato do seu dia.
2. Um projeto seu com GitHub Actions rodando testes em cada PR.
3. Uma API com banco rodando em Docker Compose, com README explicando como subir.
4. A mesma API publicada na nuvem, com deploy automático a cada push.
</Nota>

## O que costuma aparecer em vagas

- Linux, terminal e scripts.
- Docker e CI/CD (GitHub Actions, GitLab CI ou Jenkins).
- Uma nuvem (AWS é a mais pedida).
- Kubernetes e Terraform para vagas mais avançadas.
- Monitoramento e noções de segurança.

<Nota tipo="ia" titulo="DevOps e IA">
A IA é ótima para explicar mensagens de erro e escrever o primeiro rascunho de um YAML ou Dockerfile. Mas em DevOps um comando errado pode apagar um banco de produção: **nunca rode o que você não entendeu**, principalmente com permissão de administrador.
</Nota>

## Resumindo

- Base → Linux → redes e Python → Docker e CI/CD → nuvem → Kubernetes.
- Normalmente se chega em DevOps depois de passar por desenvolvimento.
- O pipeline da Unidunedev é um ótimo laboratório para começar.
