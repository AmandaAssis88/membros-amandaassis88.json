<Nota tipo="dica" titulo="Projetos para o portfólio">
1. Um app de lista de tarefas com dados salvos no aparelho.
2. Um app que consome uma API pública (clima, filmes, GitHub).
3. Um app com câmera ou mapa.
4. Grave um vídeo curto do app rodando e coloque no README do GitHub: recrutadores adoram ver funcionando.
</Nota>

## O que costuma aparecer em vagas

- Flutter (Dart) ou React Native, ou Kotlin/Swift para vagas nativas.
- Consumo de APIs REST e gerenciamento de estado.
- Arquitetura (Clean Architecture, MVVM).
- Git, testes e publicação nas lojas.

<Nota tipo="ia" titulo="Mobile e IA">
A IA acelera muito a criação de telas e o código repetitivo. Mas organizar as camadas, cuidar do estado e entender por que o app travou num aparelho específico continuam sendo trabalho seu. Peça explicações, não só código.
</Nota>

## Resumindo

- Base → orientação a objetos → um caminho (Flutter, React Native ou nativo).
- Telas, estado, API e dados locais.
- Arquitetura e publicação nas lojas fecham o ciclo.
