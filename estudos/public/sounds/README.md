# Músicas do Café de Estudos

Coloque aqui duas gravações MP3 que você tenha licença para distribuir no site:

- `trilha-1.mp3` — exibida como **Chuva no café**
- `trilha-2.mp3` — exibida como **Noite de código**

Os arquivos ficam em `estudos/public/sounds/`, pois o site de estudos tem seu próprio diretório público (diferente de `public/` na raiz do repositório).

As músicas **não estão incluídas neste commit**. O player só reproduz áudio depois do clique do usuário; salva faixa e volume no navegador e continua entre as páginas internas do site de estudos.

Para testar a partir da raiz do projeto:

```bash
npm install
npm run dev:estudos
```

Verificação de build: `npm run build:estudos`.
